# Sales & Demand Forecasting for Businesses

A Machine Learning-based Sales Forecasting Dashboard built using Streamlit and Python.

## Features

* Sales Forecasting
* Business Analytics Dashboard
* CSV Upload
* Forecast Graphs
* AI Predictions

## Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
  
## Dataset Used

[Superstore Sales Dataset (Kaggle)](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
